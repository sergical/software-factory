# AGENTS.md

Turborepo: `apps/factory` (Foreman, the eve agent; its own `AGENTS.md` and `.github/ARCHITECTURE.md` describe the agent) and `apps/web` (the target Vite todo app with the issues the factory works on). This file holds only what the repo cannot say.

- **Deploy from the repo root:** `vercel deploy --prod --yes --scope sentry`. The root `.vercel/project.json` links the Vercel project `software-factory` (team sentry, Root Directory `apps/factory`, source files outside the root directory enabled). A deploy started inside `apps/factory` uploads no lockfile, so Vercel installs with npm and the pnpm patch on `@sentry/server-utils` (cached-token counts in Sentry) is skipped. The root `.vercelignore` keeps `.eve` run records out of the upload; `turbo.json` runs in loose env mode because `eve build` reads `FACTORY_REPO`.
- **Production:** https://software-factory.sentry.dev. The `factory` label on an issue in `sergical/software-factory` runs the pipeline unattended and ends in a draft PR.
- **GitHub webhook:** Vercel Connect connector `github/foreman-agent` (`scl_EBaQO2wn2sZ8odXFTzN1A`), one trigger destination `/eve/v1/github`, events issues, issue_comment, pull_request, pull_request_review_comment, check_suite. The CLI cannot edit events or remove destinations; use `vercel api` with `PATCH /v2/connect/connectors/{id}` (`{"events":[...],"triggers":true}`) and `PATCH /v1/connect/connectors/{id}/trigger-destinations`. The GitHub App `foreman-serge` must have the same events ticked by hand in its permissions page.
- **Sentry:** org `sentry-developer-experience`, project `software-factory`; `agent/instrumentation.ts` is the single instrumentation file. Model inputs and outputs reach Sentry on every channel because `vercelAIIntegration({ recordInputs: true, recordOutputs: true })` outranks the per-call flag eve derives from the channel audience (without it, a channel with no declared audience records neither outside `eve dev`).
- **Models:** `apps/factory/agent/lib/models.ts` is all Mistral for the AI Engineer Paris talk (orchestrator, researcher, reviewer `mistral/mistral-large-3`; analyst, implementer `mistral/devstral-2`; classifier `mistral/mistral-small`) with `promptCacheKey` on every call. Keep it that way until after 2026-09-24.
